1. Dónde y cómo crear el proyecto

Ubicación recomendada

Crea el proyecto Angular en la misma carpeta raíz que tu solución .NET, como un proyecto hermano. Así todo tu sistema queda en un solo repositorio.

# Tu estructura de carpetas actual:
Microservicio.Coche/
├── Microservicio.Coche.API/
├── Microservicio.Coche.Business/
├── Microservicio.Coche.DataAccess/
└── Microservicio.Coche.DataManagement/

# Así quedaría con el frontend:
Microservicio.Coche/          ← raíz del repo
├── backend/                  ← mueve aquí tu solución .NET
│   ├── Microservicio.Coche.API/
│   └── ...
└── frontend/                 ← aquí va Angular
    └── booking-vehiculos/
Instala Angular CLI globalmente
npm install -g @angular/cli
Crea el proyecto desde la carpeta raíz
ng new booking-vehiculos --routing --style=scss --standalone

El flag --standalone usa la arquitectura moderna de Angular 17+, sin NgModules innecesarios.

Instala las dependencias clave
cd booking-vehiculos
npm install @openapitools/openapi-generator-cli -D
npm install @angular/material @angular/cdk
Genera el cliente HTTP desde tu OpenAPI/Swagger

Con tu backend corriendo en localhost, ejecuta:

npx @openapitools/openapi-generator-cli generate -i https://localhost:7291/openapi/v1.json -g typescript-angular -o src/app/core/api --additional-properties=ngVersion=17

Esto genera automáticamente todos los servicios HTTP con los tipos exactos de tu API.

Cada vez que modifiques un endpoint en .NET, vuelve a ejecutar el comando del paso 4 para regenerar el cliente. Siempre estará en sync con tu backend.

4. Código clave para conectar con tu API

environment.ts — URL base de tu API

export const environment = {
  production: false,
  apiUrl: 'https://localhost:7291/api/v1'
};

auth.interceptor.ts — agrega el JWT a cada llamada

export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(AuthService).getToken();

  if (token) {
    const authReq = req.clone({
      setHeaders: { Authorization: `Bearer ${token}` }
    });
    return next(authReq);
  }
  return next(req);
};

auth.service.ts — login y manejo del token

@Injectable({ providedIn: 'root' })
export class AuthService {
  private http = inject(HttpClient);
  private router = inject(Router);
  private readonly TOKEN_KEY = 'booking_token';

  login(correo: string, password: string) {
    return this.http.post<LoginResponse>(`${environment.apiUrl}/auth/login`, { correo, password })
      .pipe(tap(res => this.saveToken(res.Data.Token)));
  }

  getToken(): string | null {
    return localStorage.getItem(this.TOKEN_KEY);
  }

  getRol(): string | null {
    const token = this.getToken();
    if (!token) return null;
    const payload = JSON.parse(atob(token.split('.')[1]));
    return payload['http://schemas.microsoft.com/ws/2008/06/identity/claims/role'];
  }

  logout() {
    localStorage.removeItem(this.TOKEN_KEY);
    this.router.navigate(['/login']);
  }
}

Ejemplo: ReservasService usando el cliente OpenAPI generado

// Si usas el cliente OpenAPI auto-generado:
@Injectable({ providedIn: 'root' })
export class ReservasService {
  // El generador crea esto automáticamente — solo lo inyectas
  private api = inject(ReservasApiService); // auto-generado

  listarTodas() {
    return this.api.apiV1ReservasGet();
  }

  obtenerPorId(id: string) {
    return this.api.apiV1ReservasIdGet({ id });
  }

  crear(reserva: CrearReservaRequest) {
    return this.api.apiV1ReservasPost({ crearReservaRequest: reserva });
  }
}

app.config.ts — configuración principal

export const appConfig: ApplicationConfig = {
  providers: [
    provideRouter(routes),
    provideHttpClient(
      withInterceptors([authInterceptor, errorInterceptor])
    ),
    // Si usas el cliente OpenAPI auto-generado:
    { provide: BASE_PATH, useValue: environment.apiUrl }
  ]
};

6. Habilitar CORS en tu .NET para que Angular pueda llamar

Sin esto, Angular recibirá errores de CORS al llamar al backend aunque la URL sea correcta.

En tu Program.cs del proyecto API, agrega:

// Program.cs
builder.Services.AddCors(options => {
  options.AddPolicy("AngularDev", policy => {
    policy.WithOrigins("http://localhost:4200")
          .AllowAnyHeader()
          .AllowAnyMethod();
  });
});

// Antes de app.UseAuthorization():
app.UseCors("AngularDev");
El puerto 4200 es el default de Angular. Si lo cambias, actualiza el origin aquí también.
